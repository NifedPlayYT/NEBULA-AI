# NEBULA AI

Android-приложение для AI-диалогов с персонажами.

## Возможности

- Каталог встроенных и пользовательских персонажей.
- Создание собственных персонажей и локальное сохранение.
- История последних диалогов и повторное открытие чатов.
- Потоковая генерация ответов через совместимый с OpenAI API.
- Настройки адреса API, модели и пользовательского ключа.
- Переключатель «Чистый режим» для стиля речи.
- Анимации сообщений и индикатор генерации.
- Профиль и локальная статистика.

## Сборка

Release APK создаётся GitHub Actions на ветке `main`. Для работы AI пользователь указывает собственный API-ключ в настройках. Не добавляйте ключи в исходный код или APK.

## Примечания

Портреты текущего каталога — встроенные графические аватары, не загружаемые фотографии. Реальное тестирование на физических устройствах выполняется отдельно от CI-сборки.
